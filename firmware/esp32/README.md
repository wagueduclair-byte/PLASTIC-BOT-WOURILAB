# Firmware ESP32
Le sketch prépare la commande d'une goulotte orientable vers trois mini-bacs. Le classificateur retourne volontairement UNKNOWN tant qu'un vrai modèle n'est pas intégré : aucun tri automatique n'est donc annoncé.

Dépendance Arduino : ESP32Servo. Calibrer les angles et vérifier le couple sur la maquette. Alimenter le servo séparément avec une masse commune.
